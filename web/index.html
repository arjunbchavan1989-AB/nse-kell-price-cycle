Why this lane?

    Technical chart prices are dividend-adjusted; the displayed last close and market cap use the raw daily close. Wedge detection is an EMA/price-pivot proxy, not visual trendline fitting.

    Rulebook & safeguards

    The reference images describe a discretionary price-action framework, not an executable scanner. These daily-bar rules are transparent approximations. A stock is never forced into a named setup if it does not qualify; it goes into Trend / Holding or No Clear Setup.

    Precedence: Exhaustion Extension → Reversal Extension → Wedge Drop → Wedge Pop → bullish Crossback → bearish Crossback → bullish Base Break → bearish Base Break. A compatible recent setup can remain visible for 5 trading sessions. All breakout pivots and volume averages exclude today's bar. No future bars are used.

    Own NSE listing, Yahoo EOD prices and daily shares are acquired independently. Market cap is own shares × own raw EOD close. Range is mean True Range / previous close, not gap-excluding ADR. Provider history coverage below 65% of official listings, or same-session/shares/eligible-chart coverage below 95%, blocks publication. Missing symbols and newly listed histories are reported; unavailable provider data cannot be evaluated.
